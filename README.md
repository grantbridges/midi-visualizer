## Dev Setup

### Pre-Reqs

- [Python 3.14.6](https://www.python.org/downloads/release/python-3146/)
- _(Recommended)_ [VSCode](https://code.visualstudio.com/)

### Setup

- Run `python -m venv .venv` to start up virtual environment
  - _(Mac)_ Run `source ./.venv/bin/activate` to activate virtual environment
  - _(Windows)_ Run `./.venv/Scripts/activate.bat` (Windows) to activate virtual environment
- Run `python -m pip install -r ./requirements.txt` to install dependencies

### Requirements Generation

Run `py -m pigar generate` to generate fresh requirements.txt. Enter "n" for the "Try to search them on PyPI for further analysis?" prompt.
