# MIDI Visualizer

I'll update this when I have something interesting!

## Dev Startup

- Run `python -m venv .venv` to start up virtual environment
- Run `./.venv/Scripts/activate.bat` (Windows) to activate virtual environment
- Run `python -m pip install -r ./requirements.txt` to install dependencies

### Requirements Generation

Run `py -m pigar generate` to generate fresh requirements.txt. Enter "n" for the "Try to search them on PyPI for further analysis?" prompt.
